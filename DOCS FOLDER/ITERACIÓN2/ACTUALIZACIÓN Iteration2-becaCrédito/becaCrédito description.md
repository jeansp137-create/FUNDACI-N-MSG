
# Beca-crédito: descripción del requerimiento

## Iteración de requisitos

**Realice la siguiente iteración y actualice los artefactos.**

- La Fundación recibirá anualmente un aporte para otorgar becas-crédito para estudios.
- Las becas-crédito se otorgan semestralmente.
- Cada semestre, el estudiante presenta sus notas y, de acuerdo con ellas, deberá devolver el costo de la matrícula de ese semestre o el valor será condonado.
